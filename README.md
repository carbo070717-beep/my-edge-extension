## ✨ 本版本新增功能

在原扩展已有功能的基础上，本版本**新增**了以下两项功能：

1. **合集一键批量下载**
   - 支持对 B 站视频合集进行一键批量下载，无需逐个手动操作。
2. **MP3 音频下载**
   - 支持将视频直接下载为 MP3 音频格式，方便提取音频内容。

> 其余功能（视频下载、多分辨率、音视频分离合并、下载进度显示、笔记下载、评论下载等）均沿用原扩展的原始实现。

## 🛠️ 安装方法（开发者模式加载）

由于本扩展未上架商店，需通过 Edge / Chrome 的「开发者模式」手动加载：

1. 下载本仓库的 **Releases** 页面中的 `.zip` 压缩包，或直接克隆本仓库。
2. 解压 `.zip` 文件到一个固定文件夹（**解压后请勿删除或移动该文件夹**）。
3. 打开浏览器，进入扩展管理页面：
   - **Microsoft Edge**：地址栏输入 `edge://extensions/`
   - **Google Chrome**：地址栏输入 `chrome://extensions/`
4. 打开右上角的 **「开发人员模式」** 开关。
5. 点击 **「加载解压缩的扩展」**，选择第 2 步解压出的文件夹。
6. 加载成功后，扩展图标会出现在浏览器工具栏中。

> ⚠️ 注意：加载的文件夹中必须包含 `manifest.json` 文件，且该文件应位于文件夹根目录。
